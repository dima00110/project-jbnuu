## Реализация в Django

Роли — это `auth.Group`, права — `auth.Permission` из моделей:

| Роль (Group) | Ключевые permissions |
|---|---|
| `registrar` | `patients.*` (add/change/view), `appointments.*`, `queue_app.add_queueticket` |
| `admin` | все права + `schedule.*`, `auth.*` (управление пользователями) |
| `doctor` | `consultation.*`, `queue_app.view_queueticket` (+ object-level: только свои) |
| `management` | только `*.view` + доступ к разделу `reports` |

**Object-level access** (врач видит только своих пациентов/очередь) реализуется:
- переопределённым `QuerySet.get_queryset()` в менеджерах моделей,
- проверками в представлениях (`request.user.doctor` ↔ `Appointment.doctor`),
- при необходимости — `django-guardian` для per-object прав.
